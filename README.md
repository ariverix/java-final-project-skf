# Сервис сокращения ссылок

Консольный проект на Java 17. Создаёт короткие коды для URL, ограничивает число переходов и удаляет ссылки по сроку действия.

## Запуск

Нужны JDK 17+ и Maven.

```bash
mvn clean verify
mvn exec:java
```

В IntelliJ IDEA можно запустить класс `dev.ariverix.shortener.Main`.

## Команды

| Команда | Что делает |
| --- | --- |
| `create <URL> [лимит]` | Создать ссылку |
| `open <код>` | Открыть URL в браузере |
| `list`, `info <код>` | Посмотреть свои ссылки |
| `limit <код> <число>` | Изменить лимит |
| `url <код> <URL>` | Изменить адрес |
| `delete <код>` | Удалить ссылку |
| `user`, `user new`, `user use <UUID>` | Работа с пользователями |
| `notices` | Уведомления |
| `help`, `exit` | Справка и выход |

Пример:

```text
create https://example.com 3
list
open <полученный_код>
notices
```

Код вида `short://...` используется внутри программы, это не публичный веб-адрес. Для открытия нужен браузер на компьютере.

## Как устроено

- `core` — ссылки, владельцы, лимиты, TTL.
- `infra` — файлы данных, генератор кодов и браузер.
- `cli` — консольные команды.
- `application.properties` — срок жизни, лимиты и период очистки.

Ссылки и UUID сохраняются в каталоге `data/`. Он не добавляется в Git. UUID используется для доступа к своим ссылкам без пароля.

## Проверка

`mvn test` запускает 35 тестов, `mvn verify` — тесты и Checkstyle. Та же проверка настроена в GitHub Actions.

Чтобы проверить истечение ссылки вручную, укажи в `application.properties` значения `ttl.seconds=10` и `cleanup.seconds=1`. Создай ссылку и через 10 секунд проверь `list` и `notices`.
